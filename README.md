# よみ サポーター（MieeL）

もじを よむのが にがてな 子の ための「よむ ための めがね」アプリです（特別支援教育向け・iPad / iPhone）。きょうかしょや プリントの ぶんしょうを いれると、よみやすく して いっしょに よみます。

## できること
- **ふりがな（じどう）**：アプリに いれた じしょ（kuromoji.js ＋ IPA じしょ）で、はりつけた ぶんしょうの かんじに じどうで ふりがな。「ぜんぶ／1ねんの かんじは なし／2ねんまでは なし／つけない／ひらがなに する」。まちがいは タッチで なおせて、たんまつが おぼえる
- **わかちがき**：ことばの しゅるい（品詞）で ぶんせつに くぎって すきまを あける（スペースで じぶんで くぎる ことも できる）
- **よみあげ**：1ぶんずつ／ことばごと。よんで いる ところが ひかる。ことばを タッチ すると その ことばを よむ
- **1ぎょう だけ**（🔦）：いま よむ ぎょう だけ はっきり、ほかは うすく
- **みかた**：もじの おおきさ（5だんかい）・ぎょうかん・もじかん・フォント（UD ゴシック／きょうかしょたい／まる）・はいけいの いろ（6しょく）・たてがき。子どもごとに おぼえる
- **A4 プリント**：おなじ みかたで いんさつ（はいる ぶんだけ ページを わける、たてがきも）
- 🏠 ボタンで いつでも さいしょへ（よんで いる とちゅうは ながおし）

ぶんしょうは この たんまつの なかだけで しらべ・ほぞん し、インターネットには おくりません（じしょも アプリと おなじ ばしょに あります）。
